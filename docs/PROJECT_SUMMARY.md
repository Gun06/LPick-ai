# 🎵 LP 앨범 이미지 검색 시스템 - 프로젝트 요약

## 📋 프로젝트 개요

**프로젝트명**: LP 앨범 이미지 검색 시스템

- ✅ **웹 UI** 및 **REST API** 제공

## 📊 기술 스택

### 핵심 기술

| 구성 요소     | 기술          | 버전             | 용도                 |
| ------------- | ------------- | ---------------- | -------------------- |
| 임베딩 모델   | CLIP (OpenAI) | vit-base-patch32 | 이미지-텍스트 임베딩 |
| 벡터 검색     | FAISS         | CPU              | 고속 유사도 검색     |
| 웹 프레임워크 | FastAPI       | 최신             | REST API 서버        |
| 딥러닝        | PyTorch       | 2.x              | 모델 추론            |
| 프론트엔드    | Vanilla JS    | -                | 웹 UI                |

### 최적화 기법

1. **배치 처리**: 32개씩 묶어서 처리 → 10배 속도 향상
2. **L2 정규화**: 코사인 유사도 최적화
3. **IndexFlatL2**: 100% 정확도 보장
4. **FastAPI 비동기**: 동시 요청 처리
5. **체크포인트**: 중단 시 재시작 가능

## 🎨 주요 기능

### 1. 이미지 검색

**기능**: 유사한 LP 앨범 찾기

**특징**:

- 드래그 앤 드롭 업로드
- 4.53ms 초고속 검색
- Top-20 결과 표시
- 유사도 퍼센트 표시

**사용 예시**:

```python
import requests

with open('album.jpg', 'rb') as f:
    response = requests.post(
        'http://localhost:8000/search/image',
        files={'file': f},
        params={'top_k': 10}
    )
    results = response.json()
```

### 2. 텍스트 검색

**기능**: 자연어로 LP 앨범 찾기

**특징**:

- 영어 자연어 입력
- CLIP 멀티모달 검색
- 의미론적 매칭

**사용 예시**:

```python
response = requests.post(
    'http://localhost:8000/search/text',
    params={'query': 'jazz album', 'top_k': 10}
)
```

### 3. 웹 UI

**기능**: 브라우저 기반 검색 인터페이스

**특징**:

- 직관적인 디자인
- 반응형 레이아웃
- 실시간 통계
- 결과 그리드 표시

**접속**: http://localhost:8000

### 4. REST API

**기능**: 프로그래밍 방식 검색

**엔드포인트**:

- `POST /search/image` - 이미지 검색
- `POST /search/text` - 텍스트 검색
- `GET /stats` - 통계
- `GET /metadata/{id}` - 메타데이터
- `GET /image/{id}` - 이미지 파일

**문서**: http://localhost:8000/docs
